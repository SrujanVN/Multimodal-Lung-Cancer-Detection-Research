## Existing backend and state

- Flask loads trained CT and X-ray EfficientNetB3, DenseNet121, InceptionV3, and ResNet50 weights from `models/`; metadata MLP weights from `models/csv_best_model.pth` and `scaler.pkl`.
- Image inference averages available model probability outputs; backend computes Grad-CAM and optionally LIME. Metadata form/CSV inference uses the MLP and optionally LIME.
- PDF reports are generated by `/download_report` (JSON request, PDF response). `/chat` accepts JSON and returns a response.
- Authentication is stored in a Flask session. No persisted prediction history API, metrics API, model registry API, or FastAPI app exists. `/dashboard` is a template but no route is declared. `/forgot_password` is a placeholder.
- Shared design uses Poppins, blue gradients, light/dark variables, responsive CSS; landing page uses Tailwind CDN, Inter, Font Awesome, AOS and model-viewer.

## Migration choices

React will reproduce the actual home/about/info and core analysis screens using React + TypeScript + Vite. Existing CSS, images, trained weights and Flask inference remain in place. Existing HTML-returning prediction routes cannot be presented as a JSON API without changing their backend contract; the analysis form will submit to the existing Flask route and retain its real result screen. No fake history, metrics, results, or model APIs will be added. Existing login/register and report/chat contracts can be called directly.
